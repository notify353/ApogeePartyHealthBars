# Apogee Forever

Party frames and healing, keyboard and mouse actions, group alerts, everyday UI
conveniences, and tanking displays for World of Warcraft Forever 1.60.1.

Includes Apogee Heals, Keybinds, Group Alert, Essentials and Tank. Enable the
modules you want under Apogee Forever in the AddOns list, then reload. Each
module has its own settings.

For manual installation, extract all six folders into Interface/AddOns.
This edition supports Forever only. Legacy Apogee Party Health Bars profiles
are not imported, and Dungeon Guide is not included.
